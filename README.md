# Zone Manager for EllesmereUI (Unofficial)

Graphics profiles and addon sets that switch automatically with the zone type:
open world, dungeon, Mythic+, raid, delve and PvP.
Lives in EllesmereUI's options as its own pages.

> Unofficial companion addon. Not made or supported by the EllesmereUI author.
> Requires [EllesmereUI](https://www.curseforge.com/wow/addons/ellesmereui).

## Features

**Graphics profiles**
- One profile per zone type, laid out like Blizzard's Graphics Quality block, with Blizzard's own tooltips.
- Optional extras from the rest of the Graphics page; anything not in a profile is left alone.
- Only settings that actually differ are written.
- Live Preview: put a profile on screen wherever you are.

**Addon sets**
- One set of enabled addons per zone type, grouped like Blizzard's addon list.
- On a zone-type switch the addons are enabled/disabled for your character and a reload is offered (WoW only loads addons on a reload).
- Changes made in Blizzard's addon list are noticed: keep them, save them to the set, or undo.
- Optional group mode: the addon set follows the Group Finder activity of your group, without reload prompts on every zone change.
- A button in Blizzard's addon list opens the Addon Sets page.

## Usage

Open EllesmereUI's options and pick Zone Manager, or type `/zm` (`/zonemanager`).
